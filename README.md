# Pond Launcher

A minimalist Android launcher forked from [Escape Launcher](https://github.com/GeorgeClensy/Escape-Launcher).

[Download the APK](https://github.com/carruc/Pond-Launcher/releases/tag/v3.0-dev)

## What's new

- Separate swipeable pages for Home, Favorites, and All Apps.
- Stack and reorder widgets on Home.
- Configurable utility dock for Phone, Messages, Clock, and Wallet.
- Optional Google Search widget on Favorites.
- JetBrains Mono and separate controls for font size, interface scale, and dock icon size.
